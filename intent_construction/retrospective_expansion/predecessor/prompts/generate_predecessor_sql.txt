# STRICT REQUIREMENTS
- Output a single SQLite-valid SELECT statement (no comments, no trailing semicolon required).
- The result-set MUST differ from the original (different rows, different columns, or a different ordering of rows).
- "Meaningful" means a real semantic change for each CHANGE clause:
    * SELECT   → output a different set of columns/aggregates (not just an alias rename).
    * GROUP_BY → use a different grouping key (or a different combination of keys).
    * ORDER_BY → sort by a different expression (NOT just ASC↔DESC on the same key).
    * JOIN     → join a different table OR use a meaningfully different join condition/type.
- Do NOT introduce subqueries, CTEs (WITH ...), UNION, or window functions.
- Keep using the same FROM table as the original.
- If WHERE/HAVING/LIMIT reference table aliases, you MUST keep those aliases in scope so the preserved clauses still parse.
- Aliasing of the same table is allowed only if every preserved clause continues to bind correctly to the same alias names.
